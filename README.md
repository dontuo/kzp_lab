# Каталог книжок

Консольна програма для лабораторної роботи № 1 з курсу «Кросплатформні засоби
програмування» (варіант 1). Програма читає каталог книжок із CSV-файла,
перевіряє кожен запис, обчислює показники та формує звіт у консоль і текстовий файл.

## Показники

1. Кількість коректних записів.
2. Середня кількість сторінок.
3. Найдорожча книга.
4. Сумарна вартість каталогу.

## Формат входу

Файл у кодуванні UTF-8, один запис у рядку, поля розділено крапкою з комою:

```text
title;author;pages;price
```

| Поле | Тип | Обмеження |
|---|---|---|
| `title` | текст | не порожній |
| `author` | текст | не порожній |
| `pages` | ціле число | лише цифри, більше нуля |
| `price` | число з крапкою | лише цифри й необов'язкова дробова частина через крапку, не від'ємне |

Приклад:

```text
Кобзар;Тарас Шевченко;320;250.00
Лісова пісня;Леся Українка;180;145.50
```

Пробіли навколо чисел, кома замість крапки, запис `10d`, `1e3`, `NaN` чи `Infinity`
вважаються помилкою. Рядки, які не проходять перевірку, пропускаються. У звіті для кожного з них вказано
номер рядка та причину. Приклад із коректними та хибними записами – `data/input.csv`.

## Вимоги

- JDK 21 або новіший.
- Maven встановлювати не потрібно: його завантажує Maven Wrapper.

## Збірка

```text
./mvnw clean verify
```

У Windows замість `./mvnw` використовуйте `mvnw.cmd`. Команда `verify` компілює код,
запускає тести, збирає jar і виконує статичний аналіз SpotBugs.
Готовий файл: `target/lab01-1.0.0.jar`.

## Запуск

```text
java -jar target/lab01-1.0.0.jar [--help] [--version] [--input <файл>] [--output <файл>]
```

| Аргумент | Призначення | За замовчуванням |
|---|---|---|
| `--input <файл>` | вхідний CSV-файл | `data/input.csv` |
| `--output <файл>` | файл звіту | `out/report.txt` |
| `--help` | довідка | |
| `--version` | версія програми та номер CI-збірки | |

Шляхи за замовчуванням відносні, тому програму запускають з кореня проєкту.

Коди завершення: `0` – успіх, `1` – помилка роботи з файлом або немає жодного
коректного запису, `2` – неправильні аргументи.

```text
  Рядок 7: очікується 4 поля, отримано 3

  ...

Звіт записано у файл: out/report.txt
```

## Структура

```text
src/main/java/ua/lpnu/kzp/
├── Main.java             аргументи командного рядка, керування обробкою
├── BookParser.java       розбір і перевірка одного рядка
├── CatalogSummary.java   обчислення показників
├── ReportFormatter.java  формування тексту звіту
└── FileReport.java       читання та запис файлів у UTF-8
src/main/resources/version.properties   версія та номер збірки для --version
src/test/java/ua/lpnu/kzp/              тести JUnit 5
data/input.csv                          приклад вхідних даних
```
